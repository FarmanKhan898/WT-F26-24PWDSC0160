# Lab 02 — Complete Submission Guide

## 1. Objective
The lab focuses on HTML5 structure, text formatting, links, images, tables, forms, semantic HTML, GitHub Pages and deployment verification.

## 2. Completed Tasks

### Task 1 — Personal Profile Page
File: `lab2/profile.html`
- HTML5 document structure
- Name as H1
- Bio paragraph
- Profile image with alt text
- Email and telephone contact links

### Task 2 — Course Schedule Table
File: `lab2/schedule.html`
- Days are table columns
- Time slots are rows
- Course names are placed in cells
- Lunch/free period uses `colspan="5"`

### Task 3 — Navigation Menu
File: `lab2/navigation.html`
- Semantic navigation
- Home/About/Courses/Contact navigation
- Internal anchor links
- Relative links to other pages
- External UET link
- Email and telephone links

### Task 4 — Registration Form
File: `lab2/registration.html`
- Name
- Registration number
- Email
- Password
- Course dropdown
- Semester radio buttons
- Terms checkbox
- Submit button
- HTML required/minlength validation

### Task 5 — GitHub Pages Configuration
1. Push the repository to GitHub.
2. Open repository Settings.
3. Select Pages.
4. Choose deployment from the `main` branch.
5. Save the configuration.
6. Wait for the deployment to finish.
7. Open the generated GitHub Pages URL.

**Screenshot to attach:** GitHub Settings → Pages showing the selected branch and successful deployment.

### Task 6 — Landing Page
File: `lab2/index.html`
- Professional introduction
- Navigation to exercises
- GitHub link
- UET information
- Responsive layout

### Task 7 — Cross-Page Navigation
All Lab 02 pages share the same header/navigation style. JavaScript highlights the current page and each page contains a back-to-home path.

### Task 8 — GitHub Pages Customization
- `README.md` describes the project.
- `404.html` provides a custom not-found page.

### Task 9 — Form Handling
A Formspree-ready contact form is included in `navigation.html`.
Replace `YOUR_FORM_ID` with the real endpoint before testing a real submission.

### Task 10 — Performance Optimization
- Responsive CSS
- Local SVG image
- Deferred JavaScript
- Semantic HTML
- Meta description
- Descriptive alt text
- No unnecessary external image dependency

### Task 11 — Repository Structure
The project follows the structure shown in the lab handout:
`index.html`, `lab1/`, `lab2/`, `assets/css/`, `assets/js/`, `assets/images/`, and `README.md`.

### Task 12 — GitHub Pages Deployment
1. Push all files to GitHub.
2. Wait for the Pages build.
3. Open the Pages URL.
4. Test profile, schedule, navigation and registration pages.
5. Verify internal/external links.
6. Document the deployment and attach screenshots.
